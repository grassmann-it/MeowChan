# MeowChan 1.0.0-alpha.2 — early preview 🐾

**This is an optional preview. [0.9.0 remains the stable recommendation](https://github.com/tfgrass/MeowChan/releases/tag/v0.9.0).** Staying on 0.9.0 and waiting for a later release is fine.

This candidate continues the Semi + Ursa interface and the source/image-filter
plugin work introduced for 1.0. Its focus is release packaging, reader navigation
and accessibility corrections. It still needs everyday testing and native
validation across the supported platforms. This local release text does not
announce available downloads.

## What to try

- **Downloads, local reading and the gallery.** Try a small thread in Barebones,
  pause/resume, read captured posts, navigate mixed-height posts with the arrow
  keys, open media and return to the same reading context.
- **Plugins.** Open **Plugins** from the app menu or Tools. The supplied Lainchan,
  Kohlchan and image-dimensions examples are already listed. Follow the
  [first-session recipe](../plugins/using-plugins.md#first-session) for source
  files, metadata tests and image-filter access. Complete desktop packages include
  the compiler and worker; end users do not need the .NET SDK.
- **Settings and keyboard access.** Enter an invalid number, move focus away,
  save, then correct it. Try keyboard navigation at your normal display scaling.

## Before trying an upgrade

Use a separate test profile (`MEOWCHAN_PROFILE`) and media download directory.
Close every older writer before opening an existing profile. Back up the whole
profile and media, and keep exports separately. Do not run 0.9.0 and this preview
against the same data simultaneously. To return to 0.9.0, use your untouched
profile or backup; a profile changed by the preview has no promised downgrade path.

## Breaking (Library/SDK)

The preview package version is `1.0.0-alpha.2`; the separate plugin SDK protocol
contract stays `1.0.0`. `libmeowchan`, `MeowChan.PluginSdk` and the optional host
APIs are not stable in 1.x. Authors should use the exact delivered SDK package
and consult the [plugin author guide](../plugins/README.md). Local C# plugins run
with user permissions; separate worker processes are not an OS sandbox.

## Known limits

- Native package, upgrade and screen-reader validation remains incomplete,
  including Windows and macOS checks on this candidate. Linux fixture and
  automated UI results apply only to their recorded candidate and environment.
- macOS packages are ad-hoc signed and not notarized. Follow the
  [first-launch guidance](../macos-signing.md); no Developer ID approval is implied.
- Alpha testing does not replace visual user acceptance or prove provider
  availability. Plugin metadata probes do not acquire or save media.

## Report a problem

[Open an issue](https://github.com/tfgrass/MeowChan/issues/new) with the exact
version/package, OS/CPU, display scaling, view mode, reproduction steps, expected
and actual behavior. Mention a fresh or upgraded profile and enabled plugins.
Screenshots and relevant logs help. The [short Windows check](v1.0.0-alpha.2-windows-check.md)
provides a repeatable first pass.
