# MeowChan 1.0.0-alpha.2 — early preview 🐾

**This is an optional preview. [0.9.0 remains the stable recommendation](https://github.com/grassmann-it/MeowChan/releases/tag/v0.9.0).** Staying on 0.9.0 and waiting for a later release is fine.

This preview brings the Semi + Ursa interface, local reading tools, a clearer
plugin overview and explicit controls for experimental sources. A coordinated
interface update keeps the familiar appearance while making spacing, state
indicators and dialogs more consistent. It still needs
everyday testing and native validation across the supported platforms. This is
the second alpha, superseding alpha.1 for testing. The packages are built from
one source commit by GitHub Actions; `candidate-inventory.json` records their
source and validation run, and `SHA256SUMS` covers the downloads.

## What changed and what to try

- **A more coherent interface.** Downloads separate errors from retry/deadline
  information. Settings gain category navigation with clearer draft/error states.
  Archive filters and details, plugin actions, collections, export and cleanup
  dialogs use shared spacing and control roles. Gallery tools sit below the
  media, and video transport follows the active theme.
- **Reading and navigation.** Read captured posts, use the reader's arrow-key
  navigation and page controls, then return to the same context. Create named
  reader groups with manually selected threads; these groups are saved in your
  profile and do not change watches or downloads. App commands support custom
  shortcuts. Optional **Continue reading** remembers one explicitly read place
  per profile; enable it deliberately in Settings.
- **Archive tools.** Filter by multiple sources, boards and states or local
  registration dates, save searches, rate media, star threads and media, and
  keep post bookmarks and notes. Rule templates copy selected values into an
  editable draft; saving remains explicit.
- **Plugins.** The overview puts purpose, status and ordinary actions first;
  technical and developer details expand when needed. Enable/disable applies to
  the selected valid build now; saved settings and candidate choices are for
  the next start. Included source plugins add Lainchan, Kohlchan, Wizchan and Endchan; an
  image-dimensions filter is also included. Follow the [first-session recipe](../plugins/using-plugins.md#first-session).
  Complete desktop packages include the compiler and worker; end users do not
  need the .NET SDK.
- **Deliberate archive cleanup.** **Archive → Clean up archive…** previews
  threads with 0–2 verified saved media versions. Select entries, review the
  current losses and explicitly confirm permanent local deletion. Favorites,
  ratings, bookmarks/notes, reader groups, reading positions, open targets and
  unfinished work protect entries. Unknown storage is excluded. The first full
  inventory can take time on large archives. Back up before deleting.
- **Gallery and settings.** Gallery controls follow Light/Dark while retaining
  the black media background. Try keyboard navigation and invalid number input
  at your normal scaling; unfinished input and save errors should remain visible.

## Experimental sources: explicit permission and retry

**Kohlchan, Wizchan and Endchan are Experimental.** Their provider size or MD5
can differ from the file actually delivered. These three supplied plugins start
disabled when first registered in a profile. Existing profiles keep their saved
activation and permission choices. Strict checking remains the default; the
Experimental label grants no permission.

Submitting a matching URL for a disabled source opens a warning. Choose
**Activate and allow differences** (**Aktivieren und Abweichungen erlauben**)
only if you intend both to activate it and to permit provider size/MD5 differences
for that profile, plugin owner and source. Cancel grants nothing. Activation and
permission are saved separately: existing watches may resume after activation,
while the submitted URLs wait until both steps succeed. If permission saving
fails, activation may already be saved; review the displayed state and retry
explicitly. Closing does not undo a saved activation.

Use **Sources** to review or revoke **Allow provider size and MD5 mismatches**.
Manual **Enable plugin** grants no new exception; a later URL for an already
active source does not restore a revoked permission. To retry earlier failed
media after a successful permission save, open **Downloads**, select the affected
thread and choose **Retry missing media**
(**Fehlende Medien erneut versuchen**) in its details. Granting permission does
not retry old failures automatically; eligible completed work can also be retried.

Provider metadata and measured local values remain separate. Supplied provider
SHA256, local verification, complete transfers, actual byte/pixel/storage limits,
filters and cancellation remain enforced. Revoking permission blocks new
acceptance that needs it; previously accepted archived media remains readable
when its local length and SHA256 verify. A new attachment revision needs its own
valid binding. See the [permission guide](../plugins/using-plugins.md#experimental-sources-and-media-checks)
and [dated live results](../plugins/live-sources-2026-10-24.md#experimental-source-consent-follow-up-freeze09).

## Before trying an upgrade

Use a separate test profile (`MEOWCHAN_PROFILE`) and media download directory.
Close every older writer before opening an existing profile. Back up the whole
profile and media, and keep exports separately. Do not run 0.9.0 and this preview
against the same data simultaneously. To return to 0.9.0, use your untouched
profile or backup; a profile changed by the preview has no promised downgrade path.

## Breaking (Library/SDK)

The preview package version is `1.0.0-alpha.2`; the separate plugin SDK protocol
contract stays `1.0.0`. `libmeowchan`, `MeowChan.PluginSdk` and the optional host
APIs are not stable in 1.x. Authors should use the exact delivered SDK package
and consult the [plugin author guide](../plugins/README.md). Local C# plugins run
with user permissions; separate worker processes are not an OS sandbox.

Custom library providers must bind new captured attachment revisions to the
acquisition committed by the media store. Downloading without references and
later capturing only matching media metadata no longer creates an implicit
association. Update the provider logic and rebuild; preserved signatures alone
do not keep that historical behavior. See the [migration note](../../CHANGELOG.md#breaking-librarysdk)
and the [updated package consumer](../../samples/LibMeowChan.Consumer/README.md).

## Known limits

- The inventory identifies the exact source and automated validation run for
  these packages. Earlier upgrade and production-policy restart checks retain
  their own source bindings; outstanding checks are listed in the preparation
  record. This is not blanket platform or Stable acceptance.
- Physical Windows/macOS/ARM user acceptance and complete screen-reader/IME
  testing remain outstanding. Hosted native package checks and automated UI results apply only to their
  recorded candidate and environment; physical audio/GPU/FUSE behavior needs its
  own evidence.
- macOS packages are ad-hoc signed and not notarized. Follow the
  [first-launch guidance](../macos-signing.md); no Developer ID approval is implied.
- The selected experimental-source originals passed a recorded consent/retry
  follow-up. Its fresh offline host was in the same OS process; this does not
  prove a desktop restart or wider provider availability. Historical metadata
  conflicts and their unproven deployed causes remain in the dated report.
- Automatic settings-backup recovery disables recovered experimental-source
  exceptions until you explicitly grant them again. Valid primary settings keep
  their saved choices. Package, upgrade and native input results retain their
  separate scope in the preparation record.
- Activation-dialog checks at 1×/1.5×/2× and selected narrow archive/saved-search
  checks passed locally. Package and native acceptance remain separate. Plugin
  metadata probes do not acquire or save media.

## Report a problem

[Open an issue](https://github.com/grassmann-it/MeowChan/issues/new) with the exact
version/package, OS/CPU, display scaling, view mode, reproduction steps, expected
and actual behavior. Mention a fresh or upgraded profile and enabled plugins.
Screenshots and relevant logs help. The [short Windows check](v1.0.0-alpha.2-windows-check.md)
provides a repeatable first pass.
