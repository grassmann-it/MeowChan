# MeowChan 1.0.1 🐾 — Less waiting while downloads run

This performance maintenance release improves responsiveness when downloads,
archive updates and gallery navigation happen together.

## What's improved

- **Keep using the workspace during slow saves.** Download state is prepared in
  the background, so UI queries no longer wait on slow download commits.
  Interactive work is bounded, and repeated preference changes retain the latest
  pending value.
- **Less repeated UI work.** Progress updates are coalesced, download rows update
  incrementally, and covered archive and reader views defer expensive refreshes
  until needed. Status, errors and controls can still request prompt updates.
- **Less filter staging overhead.** Temporary-file accounting replaces repeated
  directory scans for each data block, retaining conservative storage limits,
  recovery and cancellation handling.
- **More focused gallery work.** Indexed media associations and on-demand context
  preparation reduce repeated work. Covered views stop starting unnecessary
  thumbnails. Originals are still fully verified before cached video posters
  are used.
- **Better coordinated video switching and closing.** Playback changes share
  actual cleanup completion, keep resources owned until native work finishes,
  and prevent stale operations from controlling a newer video.
- **More stable reader and window transitions.** Late reply-count updates retain
  the visible reader post, archive favorites stop querying a closed session, and
  macOS fullscreen restoration respects a later request to return to Normal.

Media integrity checks, explicit saves, final preference saves and selection
identity remain enforced.

## Performance feedback

Early user feedback reports better responsiveness. The original Windows hang
with an external USB SSD has not been formally demonstrated fixed; improvements
vary with storage and workload.

[Report a problem](https://github.com/grassmann-it/MeowChan/issues/new) with the
exact version/package, OS, enabled plugins and reproduction steps. For performance
issues, include whether downloads are active and whether profile and media
storage are internal or connected through USB.
