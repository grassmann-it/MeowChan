# MeowChan 1.1.1

MeowChan 1.1.1 builds on [1.1.0](v1.1.0.md) with a more useful Danbooru workspace, a compact Tagging page and more room for reading.

## Highlights

- **Pick up a Danbooru search where you left off.** Booru is in the default navigation. Searches open in tabs, can be restored on startup and have a dedicated **Watchers** button beside the tabs.
- **Browse Booru results in a gallery.** Switch between List, Grid and Gallery on the same result page. The inline gallery and separate viewer share controls, keyboard navigation and tag tools.
- **See tagging progress at a glance.** A compact header puts the start or continue action beside the stamp and a count such as **0 of N results**.
- **Give posts and media more room.** The Reader hides the title bar in full screen. Reader, Archive and Media share a consistent media-sidebar header. Downloads groups its table actions and highlights the entire focused row.
- **Keep bundled Danbooru working across installs.** Eligible 1.1.0 profiles reconnect to the verified 1.1.1 build even when you install it in a new folder. The startup notice offers a repair review when needed.

[See the 1.1.1 desktop screenshots](../screenshots/1.1.1/README.md).

## Toolbars, Downloads and Tagging

- The Reader keeps **Full screen** at the right edge, immediately before the sidebar switches, even at narrow widths. Full screen hides the title bar by default. Move the pointer to the top edge to reveal it temporarily. On the Media page, the tag-list and media-sidebar switches sit together. **Find** and **Tags** show when their Reader tools are open and let you close them from the same buttons.
- The media-sidebar header uses the same layout in the Reader, Archive and Media page. It keeps the position and actions together and gives long file details room to wrap below. Sidebar switches use consistent panel icons, and workspace actions use matching icons across toolbars and menus.
- Downloads aligns **Search** and **Copy URLs** with the Threads and Boards tabs and places **Columns** and **Details** on the right. The table highlights the focused row as you move between its cells.
- Tagging puts **Start tagging** or **Continue tagging** beside queue progress and a summary that opens the stamp editor. The progress line uses **0 of N results** for a fresh queue and counts finished and skipped entries against the active queue scope. The compact group and state filters also show how many entries match. With a selection, **Edit tags…** and **Mark as finished** stay visible. Other selection actions, including applying the stamp, are under the selection’s **More** button. Use Space to start the walk while the start button is focused or to toggle the focused entry in the list or grid. **Without tags** shows files with a known count of zero. The media index supplies tag counts for matching attachment revisions.

## Danbooru searches and gallery

- Booru is shown by default in new profiles and profiles that used the 1.1.0 default footer. Saved choices to hide Booru or disable its source still apply.
- New searches open in a new tab by default. Change the destination in Settings or press Shift+Enter to use the other destination. **Duplicate tab** copies the displayed search and results. The **Watchers** button beside the search tabs opens or brings forward the closable Watchers overview. Each search tab retains its own current result and marked posts as you switch tabs.
- **Restore Booru searches on startup** saves search tabs and a bounded set of results in the current profile. It is on by default. You can set the saved-result limit to zero to keep just the searches. Restoring tabs does not rerun them.
- Switch between List, Grid and Gallery on the current result page. The inline gallery and separate viewer share a toolbar, navigation shortcuts, source tags and private tags for saved media. Both start with the preview and can load a larger, reduced-size image for the current post. Returning from the gallery brings you back to the current hit.
- **Download all of this search** queues originals from up to five pages of 20 results each. The summary reports queued, already queued, already saved, unavailable and failed originals, and explains why collection stopped.
- Saved Danbooru media can carry private local tags. Original-download actions report their outcome, including refusals that still need attention.

## Other fixes and limits

- Returning to the archive Reader reuses ready or still-loading previews and restarts cancelled scans. Failed attachment previews can be retried in place. Links and post references on later lines respond to pointer input again.
- The gallery footer stays visible while its controls are in use and can hide again when idle. Its tooltips no longer intercept the pointer. The local gallery also supports rating with 1–5, clearing a rating with 0, colour labels with 6–9 and 1:1 zoom with Z.
- Reading-history cleanup follows saved settings and keeps existing history when reads or backups fail. Statistics reset reports whether it removed the saved copies. Gallery navigation uses the saved media order across bounded windows in a single thread.
- Original exports support a filename template with a preview. Manual import verifies an existing copy before skipping it and reports which tags were added or missing. Multi-thread media retry reports what was retried, already saved or already queued.
- On the Media page, a command moves to the next shown file without media tags. In Diagnostics, the overview groups messages and explains what a bulk retry covers.
- Danbooru galleries page within the current result page. Size, pixel and time limits can leave the preview in place. Loading an original remains a separate download action.
- Opening a v1, v2 or dogfood v3 tagging queue leaves its files untouched. The first edit to a v3 queue writes both the previous revision in `tag-queue.json.bak` and the edited revision in `tag-queue.json` in v2 format. The editing session resolves attachment revision keys in memory.

## Upgrading from 1.1.0

Back up your profile before starting 1.1.1 with it. The profile can reconnect the bundled Danbooru plugin to its new installation path. The automatic migration applies to an unpinned, verified build from the same delivery slot with an unchanged declaration, compatible saved settings and no special permissions to carry over. MeowChan updates the saved build selection and keeps the previous build record for rollback. If the saved Danbooru build needs review, open the repair dialog from the startup warning. Changed manually installed builds may need to be selected explicitly on the Plugins page.

Saved choices to hide Booru or disable its source still apply. If you used the 1.1.0 default footer, Booru is now shown where your workspace view has room for it, or under **More**. Use **Show Booru actions** in Settings → Interface → Footer to hide it.

For profiles coming from 1.0.2, see the [1.1.0 upgrade notes](v1.1.0.md#upgrading-from-102). Package-level upgrade validation from 1.0.2 to 1.1.1 remains open.

## Deutsch

MeowChan 1.1.1 baut auf [1.1.0](v1.1.0.md) auf und überarbeitet die Danbooru-Suche, die Tagging-Seite und die Werkzeuge rund ums Lesen.

### Highlights

- **Danbooru-Suchen wieder aufnehmen.** Booru gehört zur Standardnavigation. Suchen öffnen sich in Tabs und können beim Start wiederhergestellt werden. Ein eigener Knopf neben den Tabs öffnet die Suchbeobachtungen.
- **Booru-Treffer als Galerie durchsuchen.** Liste, Raster und Galerie teilen sich dieselbe Ergebnisseite. Eingebettete Galerie und separates Fenster verwenden dieselben Bedienelemente, Tastenkürzel und Tag-Werkzeuge.
- **Den Tagging-Fortschritt im Blick behalten.** Im kompakten Kopf stehen **Taggen starten** oder **Weiter taggen** neben dem Stempel und einer Anzeige wie **0 von N Treffern**.
- **Mehr Platz für Beiträge und Medien.** Der Reader blendet im Vollbild die Titelleiste aus. Reader, Archiv und Medien verwenden einen einheitlichen Kopf für die Medien-Seitenleiste. Downloads hebt die ganze fokussierte Zeile hervor.
- **Danbooru beim Update mitnehmen.** Geeignete 1.1.0-Profile übernehmen den geprüften mitgelieferten Build aus dem neuen Installationsordner. Falls eine Prüfung nötig ist, führt die Startmeldung zur Reparatur.

### Details

- **Booru-Navigation und Updates.** Booru erscheint standardmäßig auch in Profilen mit der 1.1.0-Standard-Fußleiste. Gespeicherte Ausblendungen und deaktivierte Quellen bleiben erhalten. Nach einem Update in ein neues Installationsverzeichnis kann MeowChan für ein nicht angeheftetes Plugin den geprüften Build aus demselben Auslieferungs-Slot übernehmen. Dafür muss die Deklaration unverändert sein und es dürfen keine Sonderberechtigungen zu übertragen sein. Falls Danbooru eine Prüfung braucht, öffnet die Startmeldung den Reparaturdialog.
- **Reader und Medien.** Im Reader stehen Vollbild und die Schalter für Thread-Liste und Medien-Seitenleiste rechts. Am oberen Bildschirmrand lässt sich die Titelleiste vorübergehend einblenden. Auf der Medienseite sind Tag-Liste und Medien-Seitenleiste ebenfalls gruppiert. **Suchen** und **Tags** zeigen ihren aktiven Zustand und lassen sich über denselben Schalter schließen. Einheitliche Symbole kennzeichnen die Seitenleisten-Schalter und wiederkehrende Aktionen.
- **Booru-Tabs und Suche.** Neue Suchen öffnen standardmäßig einen neuen Tab. In den Einstellungen kannst du das Ziel ändern. Umschalt+Eingabe verwendet das jeweils andere Ziel. **Tab duplizieren** kopiert die angezeigte Suche samt Ergebnissen. Die Suchbeobachtungen lassen sich als Tab schließen. **Booru-Suchen beim Start wiederherstellen** speichert Such-Tabs und begrenzte Ergebnisse im Profil. Mit dem Ergebnislimit 0 bleiben nur die Suchen erhalten. Beim Wiederherstellen wird die Suche nicht erneut ausgeführt.
- **Booru-Galerie und Downloads.** Liste, Raster und Galerie teilen sich die aktuelle Ergebnisseite. Die Galerie zeigt zuerst die Vorschau und lädt für den aktuellen Post bei Bedarf eine größere, verkleinerte Fassung. Die Leiste gruppiert Navigation, Auswahl, Aktionen und Fenstersteuerung. **Alles aus dieser Suche laden** reiht Originale aus höchstens fünf Seiten mit je 20 Treffern ein und zeigt die Ergebnisse und den Abbruchgrund. Gespeicherte Danbooru-Medien können private lokale Tags erhalten.
- **Downloads-Tabelle.** Suche und URL-Kopieraktion stehen bei den Tabs für Threads und Boards, Spalten und Details rechts. Beim Wechsel zwischen Zellen bleibt die ganze fokussierte Zeile hervorgehoben.
- **Rückkehr zum Reader.** Fertige und laufende Vorschauen bleiben beim Zurückkehren erhalten, abgebrochene Scans starten erneut. Fehlgeschlagene Anhangsvorschauen lassen sich an Ort und Stelle erneut laden. Links und Post-Verweise in späteren Textzeilen reagieren wieder.
- **Taggen.** Der Fortschritt zählt erledigte und übersprungene Einträge im gewählten Warteschlangenbereich. Die kompakten Filter zeigen die Anzahl der passenden Einträge. Bei einer Auswahl bleiben **Tags bearbeiten…** und **Als erledigt markieren** sichtbar. Weitere Aktionen stehen unter **Mehr**. Die Stempelzusammenfassung öffnet den Editor. **Ohne Tags** erfasst nur Medien mit bekannter Tag-Anzahl null. Beim Öffnen einer Warteschlange im Format v1, v2 oder Dogfood-v3 bleiben die Dateien unverändert. Die erste Änderung an einer v3-Warteschlange speichert den vorherigen und den neuen Stand im v2-Format.
- **Galerie-Fußleiste.** Beim Bedienen bleibt sie sichtbar, im Leerlauf kann sie wieder ausblenden. Tooltips fangen den Mauszeiger nicht mehr ab. Die lokale Galerie unterstützt 1–5 für Bewertungen, 0 zum Löschen einer Bewertung, 6–9 für Farbmarkierungen und Z für die 1:1-Ansicht.
- **Weitere Korrekturen.** Der Leseverlauf bleibt bei Lese- oder Backupfehlern erhalten. Der Statistik-Reset meldet, ob gespeicherte Kopien entfernt wurden. Originalexporte unterstützen eine Dateinamenvorlage mit Vorschau. Beim manuellen Import wird eine vorhandene Kopie vor dem Überspringen geprüft.

Sichere vor dem Update dein Profil. Die [Download-Tabelle](#downloads) führt die Pakete mit Plattformbezeichnung und nummerierten Dateinamen auf. Die Ergebnisse der Windows- und macOS-Abnahme ergänzt Tom im Abschnitt [Validation status](#validation-status).
