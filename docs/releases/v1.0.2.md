# Draft — MeowChan 1.0.2: media controls that remember

**Preparation draft, 2026-10-29. Not published; release-candidate and native
package validation are still pending. No download links are available here.**

This proposed release focuses on spending less time adjusting the viewer and
more time viewing saved media.

## Implemented in the current local source

- **Keep your viewing choices.** Repeat mode, media focus and overlay choices are
  remembered for the profile. Existing profiles initially keep the docked layout.
- **Choose how to move through media.** Manual, Repeat and mixed Slideshow modes
  keep single-video repeat separate from automatic navigation. Images use a chosen
  display period, videos advance at their actual end, and slideshow starts explicitly.
- **Give media more room.** Hover at the bottom edge for transport and at the
  right edge for post context; moving in the picture's center does not reopen
  panels. They stay open for interaction, then collapse on leaving. Pointer focus
  on slideshow Start no longer pins controls. Keyboard/gesture/menu protection
  remains. Post backgrounds are translucent, text opaque; unsupported native
  transparency keeps controls docked and reachable. Controls overlay and auto-hide
  are one paired choice; subtle borderless edge arrows appear briefly on mouse
  motion, without reopening panels from movement in the center.
- **More reliable interaction.** Seeking no longer leaves the playhead frozen by
  hover/focus. Navigation recovers after video-to-image focus loss, while focused
  sliders retain their own arrow keys. The first navigation key works with hidden
  controls. First/manual video autoplay is independent of saved Slideshow mode
  and never silently starts automatic next. Seek, volume and panel interaction
  preserve native play/pause intent. Old Settings drafts preserve newer volume edits.
- **Read without losing height.** In narrow windows, the thread-reader arrow cross
  is a true overlay instead of a reserved bottom strip. Scrollable end clearance
  keeps the final post readable, with scrollbar and pagination unobstructed.
- **Useful thread labels after restart.** Known real titles are restored locally;
  missing titles can use a cleaned opening-post excerpt without inventing source metadata.
- **Dismiss a message without losing the diagnosis.** Banner and toast close
  actions suppress matching repeats for the current session. Diagnostics remain
  available, and passive popup expiry is not acknowledgement.
- **Clearer startup diagnostics.** Plugin failures carry more precise phase
  information without silently switching selected candidates or permissions.

## Before publication

The source-level packaged-playback contract now retains repeat (schema 2), but
fresh native and packaged validation of the final frozen source is still required. Existing local Linux
passes do not substitute for Windows/macOS overlay/input or physical audio proof.
The user's original Windows/Leftypol startup incident remains unconfirmed, not
advertised as fixed. Ambiguous legacy title text is not destructively guessed away.

Bindable gallery actions and transient slideshow-status explanations are included
in the local implementation, without adding default shortcut gestures. Speed,
shuffle and whole-gallery repeat were not added. Track final scope and gates in
[release preparation](v1.0.2-preparation.md).
