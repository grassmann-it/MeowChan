# Alpha2: later manual draft and asset handoff

**Reviewable instructions only. No remote action has been executed or authorized.**
Keep Alpha2 as a prerelease and keep stable Latest at `v0.9.0`. This procedure
creates a fresh private draft and attaches verified assets. It does not publish,
create a local Git tag, push, dispatch Actions or alter the 0.9 uploader.

## Required input and review boundary

First finish the [candidate record](v1.0.0-alpha.2-preparation.md#current-candidate-record)
and review the [release body](v1.0.0-alpha.2.md) against actual results. Obtain
separate authorization for draft creation and upload before running the remote
example below. Publication is a separate later action; no publish command is
included here.

Use a fresh output from the existing full-matrix assembler, after independently
verifying that its single originating Actions run completed successfully at the
exact committed Alpha2 source. All Windows, Linux x64/arm64, macOS x64/arm64 and
three developer-package inputs must come from that run. This is a template,
not an assertion that such a run currently exists:

```sh
python3 scripts/assemble-prerelease.py \
  --artifacts-root /absolute/reviewed/same-run-artifacts \
  --source-commit FULL_40_CHARACTER_COMMITTED_SOURCE_SHA \
  --version 1.0.0-alpha.2 \
  --run-id ACTUAL_SUCCESSFUL_ACTIONS_RUN_ID \
  --source-base /absolute/reviewed/MeowChan-0.9.0-video-sources.tar.gz \
  --output /absolute/new-alpha2-staged
```

The assembler validates exact product identity, source/native report bindings,
public API release review, developer packages, legal files and corresponding
sources. It does not fetch or independently verify Actions run status. Its full
output is **16 inventory assets plus `candidate-inventory.json` and `SHA256SUMS`**:

| Kind | Exact files (`V` means `1.0.0-alpha.2`) |
| --- | --- |
| Windows | `MeowChan-V-win-x64.zip` |
| Linux, each of `linux-x64` and `linux-arm64` | `MeowChan-V-RID.AppImage`, `MeowChan-V-RID-bundled-vlc.tar.gz`, `MeowChan-V-RID-system-vlc.tar.gz`, `MeowChan-V-RID-video-sources.tar.gz` |
| macOS | `MeowChan-V-osx-x64.dmg`, `MeowChan-V-osx-arm64.dmg`, `MeowChan-V-macos-video-source-overlay.tar.gz` |
| Immutable upstream video-source base | `MeowChan-0.9.0-video-sources.tar.gz` (725131331 bytes; SHA256 `bf556da3dd1fb511dafb81f684a0bb6fc38e7cb7b91081e9ac0c307bd0771bfa`) |
| Developer packages | `libmeowchan.V.nupkg`, `MeowChan.PluginSdk.V.nupkg`, `MeowChan.PluginHost.V.nupkg` |
| Inventory and checksums | `candidate-inventory.json`, `SHA256SUMS` |

The historical source base intentionally retains its 0.9 name and upstream
bytes; it is not a retained 0.9 application binary. The macOS overlay and paired
Linux source companions must accompany their corresponding binaries. Review
`legal_sha256` against committed `LICENSE`, `THIRD-PARTY-NOTICES.md` and the seven
native legal/source documents listed in `scripts/check-desktop-package.py`.
NuGet packages include their own checked license. Keep all companions together;
do not upload only desktop binaries.

A locally built Linux-only candidate is useful evidence but cannot be passed to
this full-matrix procedure. Do not invent its missing platforms/run IDs or change
the inventory schema to make it pass. No current download URL is promised here.

## Concrete later draft/upload example

Save the following reviewed example as a temporary script **outside the candidate
folder**. It requires Python 3.11+, `gh`, an authenticated account with repository
release access, a new receipt directory and seven explicit arguments. Pin the
inventory/body SHA256 values from the review, not by recalculating them silently
at upload time. Keep the candidate immutable through upload. All `gh` invocations
use argument arrays and structured request bodies; no body interpolation, shell
execution or `--clobber` is used. Existing drafts/assets are not overwritten.

The first network operations are read-only checks. Any mismatch stops. If upload
fails after draft creation, retain the receipt directory and private draft for
review; do not rerun blindly or publish a partial draft.

```python
import argparse
import hashlib
import json
from pathlib import Path
import re
import subprocess
from urllib.parse import urlencode

p = argparse.ArgumentParser()
for name in ('candidate', 'notes', 'receipt', 'inventory_sha256',
             'notes_sha256', 'source_commit', 'run_id'):
    p.add_argument(name)
a = p.parse_args()
repo, version, tag = 'grassmann-it/MeowChan', '1.0.0-alpha.2', 'v1.0.0-alpha.2'
root, notes, receipt = Path(a.candidate), Path(a.notes), Path(a.receipt)

def require(ok, message):
    if not ok:
        raise ValueError(message)

def digest(path):
    require(path.is_file() and not path.is_symlink(), 'Not a regular file: ' + str(path))
    with path.open('rb') as stream:
        return hashlib.file_digest(stream, 'sha256').hexdigest()

def unique(pairs):
    result = {}
    for key, value in pairs:
        require(key not in result, 'Duplicate JSON key: ' + key)
        result[key] = value
    return result

def gh(*args):
    return json.loads(subprocess.check_output(['gh', *args]))

require(root.is_absolute() and root.is_dir() and not root.is_symlink(), 'Candidate directory')
require(notes.is_absolute() and receipt.is_absolute() and not receipt.exists(), 'Paths/receipt')
require(re.fullmatch(r'[0-9a-f]{40}', a.source_commit), 'Full source SHA required')
require(re.fullmatch(r'[1-9][0-9]*', a.run_id), 'Real Actions run ID required')
for value in (a.inventory_sha256, a.notes_sha256):
    require(re.fullmatch(r'[0-9a-f]{64}', value), 'Reviewed SHA256 required')
require(digest(root / 'candidate-inventory.json') == a.inventory_sha256, 'Inventory changed')
require(digest(notes) == a.notes_sha256, 'Release body changed')
inv = json.loads((root / 'candidate-inventory.json').read_text(), object_pairs_hook=unique)
require(inv['schema'] == 'meowchan.prerelease-candidate.v1' and inv['channel'] == 'prerelease', 'Channel')
require(inv['version'] == version and inv['source_commit'] == a.source_commit
        and str(inv['actions_run_id']) == a.run_id, 'Candidate identity')
base = 'MeowChan-0.9.0-video-sources.tar.gz'
base_sha = 'bf556da3dd1fb511dafb81f684a0bb6fc38e7cb7b91081e9ac0c307bd0771bfa'
expected = {f'MeowChan-{version}-win-x64.zip', base,
            f'MeowChan-{version}-osx-x64.dmg', f'MeowChan-{version}-osx-arm64.dmg',
            f'MeowChan-{version}-macos-video-source-overlay.tar.gz'}
for rid in ('linux-x64', 'linux-arm64'):
    for suffix in ('.AppImage', '-bundled-vlc.tar.gz', '-system-vlc.tar.gz', '-video-sources.tar.gz'):
        expected.add(f'MeowChan-{version}-{rid}{suffix}')
for package in ('libmeowchan', 'MeowChan.PluginSdk', 'MeowChan.PluginHost'):
    expected.add(f'{package}.{version}.nupkg')
rows = inv['assets']
require(len(rows) == 16 and {row['file'] for row in rows} == expected, 'Exact 16 assets')
require({path.name for path in root.iterdir()} == expected | {'candidate-inventory.json', 'SHA256SUMS'},
        'Unexpected or missing staged file')
for row in rows:
    name = row['file']
    require(Path(name).name == name and '/' not in name and '\\' not in name, 'Unsafe name')
    path = root / name
    require(type(row['bytes']) is int and path.stat().st_size == row['bytes'], 'Length: ' + name)
    require(digest(path) == row['sha256'], 'Hash: ' + name)
    require(row['source_commit'] == (None if name == base else a.source_commit), 'Source: ' + name)
require((root / base).stat().st_size == 725131331 and digest(root / base) == base_sha, 'Source base')
require(inv['source_base'] == {'file': base, 'bytes': 725131331, 'sha256': base_sha}, 'Base inventory')
checksummed = expected | {'candidate-inventory.json'}
require((root / 'SHA256SUMS').read_bytes() == ''.join(
    f'{digest(root / name)}  {name}\n' for name in sorted(checksummed)).encode(), 'Exact SHA256SUMS')
files = sorted(checksummed | {'SHA256SUMS'})
bound = {name: {'name': name, 'size': (root / name).stat().st_size,
                'digest': 'sha256:' + digest(root / name)} for name in files}

run = gh('run', 'view', a.run_id, '--repo', repo, '--json', 'headSha,status,conclusion')
require(run == {'headSha': a.source_commit, 'status': 'completed', 'conclusion': 'success'}, 'Run status/source')
latest = gh('api', f'repos/{repo}/releases/latest')
require(latest['tag_name'] == 'v0.9.0' and latest['draft'] is False
        and latest['prerelease'] is False, 'Stable Latest changed')
receipt.mkdir(parents=True, exist_ok=False)
(receipt / 'reviewed-inputs.json').write_text(json.dumps({
    'repository': repo, 'source_commit': a.source_commit, 'run': run,
    'inventory_sha256': a.inventory_sha256, 'notes_sha256': a.notes_sha256,
    'latest_before': latest, 'assets': list(bound.values())}, indent=2) + '\n')
payload = {'tag_name': tag, 'target_commitish': a.source_commit,
           'name': 'MeowChan ' + version, 'body': notes.read_text(encoding='utf-8'),
           'draft': True, 'prerelease': True, 'make_latest': 'false'}
request = receipt / 'create-draft.json'
request.write_text(json.dumps(payload, ensure_ascii=False, indent=2) + '\n')
release = gh('api', '--method', 'POST', f'repos/{repo}/releases', '--input', str(request))
(receipt / 'created-draft.json').write_text(json.dumps(release, indent=2) + '\n')
release_id = release['id']
require(type(release_id) is int, 'Numeric release ID')
endpoint = f'repos/{repo}/releases/{release_id}'

def check_draft(value):
    require(value['tag_name'] == tag and value['target_commitish'] == a.source_commit
            and value['draft'] is True and value['prerelease'] is True, 'Draft identity/state')

check_draft(release)
require(not release['assets'], 'Fresh draft must be empty')
for name in files:
    check_draft(gh('api', endpoint))
    require(digest(root / name) == bound[name]['digest'][7:], 'File changed during upload')
    asset = gh('api', '--method', 'POST',
               f'https://uploads.github.com/repos/{repo}/releases/{release_id}/assets?' + urlencode({'name': name}),
               '-H', 'Content-Type: application/octet-stream', '--input', str(root / name))
    (receipt / (name + '.upload.json')).write_text(json.dumps(asset, indent=2) + '\n')
    require(asset['state'] == 'uploaded'
            and all(asset.get(key) == value for key, value in bound[name].items()), 'Uploaded asset mismatch')
final = gh('api', endpoint)
check_draft(final)
require(len(final['assets']) == len(files) and {asset['name'] for asset in final['assets']} == set(files),
        'Final remote asset inventory')
for asset in final['assets']:
    require(asset['state'] == 'uploaded' and all(
        asset.get(key) == value for key, value in bound[asset['name']].items()), 'Final remote hash/size')
require(digest(root / 'candidate-inventory.json') == a.inventory_sha256
        and digest(notes) == a.notes_sha256, 'Reviewed input changed')
after = gh('api', f'repos/{repo}/releases/latest')
require(after['id'] == latest['id'] and after['tag_name'] == 'v0.9.0', 'Latest changed')
(receipt / 'verified-draft.json').write_text(json.dumps({
    'draft': final, 'latest_after': after, 'uploaded_inventory_verified': True,
    'published': False}, indent=2) + '\n')
print('Verified private prerelease draft:', final['html_url'])
```
