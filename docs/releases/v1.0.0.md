# MeowChan 1.0.0 🐾

MeowChan 1.0 brings a reworked interface, more sources and local filters, and new
ways to read, organize and clean up your archive. The Semi + Ursa interface keeps
the familiar appearance while giving actions, spacing, errors and dialogs a
more consistent structure.

**Back up your whole profile and media before upgrading.** If you encounter
problems, please report them. You can also try
[0.9.0](https://github.com/grassmann-it/MeowChan/releases/tag/v0.9.0) with an
untouched profile or pre-upgrade backup; do not open a profile already changed
by 1.0 in 0.9.0.

## What changed

- **A clearer workspace.** Downloads separate errors from retry/deadline
  information. Settings have category navigation and clearer draft/error states.
  Archive filters, plugin actions, collections, exports and cleanup dialogs share
  consistent spacing and control roles. Barebones, Simple and Advanced retain
  their different levels of detail.
- **Reading and navigation.** Read captured posts with arrow-key navigation and
  page controls. Save named reader groups containing manually selected threads;
  groups do not change watches or downloads. Customize app shortcuts. Optional
  **Continue reading** remembers one explicitly read place per profile; enable
  it in Settings and return through the topbar book button or menu.
- **Archive organization.** Filter by multiple sources, boards and states or
  local registration dates, save searches, rate media, star threads and media,
  and keep post bookmarks and notes. Rule templates copy selected values into an
  editable draft; saving remains explicit.
- **Correct archive counts.** The **Saved versions** column counts archived
  media versions across a thread's recorded media folders, independently of the
  current download job and media filters. Missing files and files whose length
  differs from the manifest are not counted; unreadable storage appears as
  unavailable, rather than an empty archive. This count checks file presence and
  length; opening media still
  verifies its checksum.
- **16 supplied plugins: 11 sources and five local filters.** Sources are
  **4chan, 8kun, Lainchan, Kohlchan, Wizchan, Endchan, 2ch, Leftypol, Uboachan,
  ZZZchan and SushiChan**. The plugin overview puts purpose, status and ordinary
  actions first, with expandable developer details. Enable/disable applies to
  the selected valid build immediately; saved settings and candidate choices
  apply at the next start. The delivery also includes **14 editable plugin
  examples**, plus the compiler and worker, so end users need no .NET SDK.
  See the [first-session guide](https://github.com/grassmann-it/MeowChan/blob/v1.0.0/docs/plugins/using-plugins.md#first-session).
- **Local media filters.** Alongside image dimensions, choose file-size and
  original-name rules, a SHA-256 blocklist, animation/actual-format checks, or PNG
  metadata-field presence checks. Filters inspect locally staged files before
  archive publication. One filter applies per effective rule; filter chaining
  and automatic tagging are not included. See the
  [filter guide](https://github.com/grassmann-it/MeowChan/blob/v1.0.0/docs/plugins/local-media-filters.md).
- **Deliberate cleanup.** **Archive → Clean up archive…** previews threads with
  0–2 verified saved media versions. Favorites, ratings, bookmarks/notes, reader
  groups, reading positions, open targets and unfinished work protect entries.
  Unknown storage is excluded. Review the current losses and explicitly confirm
  permanent local deletion. The first full inventory can take time on a large
  archive; back up before deleting.
- **Gallery and video.** Gallery controls follow Light/Dark while the media
  background stays black, with tools below the media. Video has one Play/Pause
  control, seeking when supported, volume/mute and optional repeat for the current
  media. Repeat resets when
  changing media; audio controls explain when there is no audio track or usable
  audio output.

## Experimental sources and media checks

**Kohlchan, Wizchan, Endchan, 2ch, Leftypol, Uboachan, ZZZchan and SushiChan
are Experimental.** These sources start disabled when first registered in a
profile. Existing profiles retain saved activation and permission choices. The
Experimental label itself grants no exception.

For **2ch, Uboachan, ZZZchan and SushiChan**, submitting a matching URL offers
activation with strict integrity checks. These four sources have no
provider-mismatch permission. Uboachan's supplied per-attachment SHA-1 values
are verified. Approximate provider sizes remain separate raw hints rather than
invented exact byte expectations. 2ch original redirects are checked against
explicitly declared original-media hosts at every hop.

For **Kohlchan, Wizchan, Endchan and Leftypol**, provider size or MD5 can differ
from delivered bytes. **Activate and allow differences**
(**Aktivieren und Abweichungen erlauben**) explicitly activates the source and
permits provider size/MD5 differences for the current profile, plugin owner and
source. Cancel grants nothing. Activation and permission are saved separately:
existing watches may resume after activation, while submitted URLs wait for both
steps to succeed. If permission saving fails, activation may already be saved;
review the state and retry explicitly. Closing does not undo saved activation.

Use **Sources** to review or revoke **Allow provider size and MD5 mismatches**.
Manual **Enable plugin** grants no exception; a later URL for an active source
does not restore a revoked permission. Retry previous failed media explicitly
through **Downloads → thread details → Retry missing media**; granting permission
does not automatically retry old failures.

Provider metadata and measured local values stay separate. Supplied provider
SHA-1/SHA-256, local verification, complete transfers, actual byte/pixel/storage
limits, filters and cancellation remain enforced. Revoking permission blocks new
acceptance that needs it; previously accepted archive media remains readable
when its local length and SHA-256 verify. New attachment revisions need their
own valid binding. See the
[permission guide](https://github.com/grassmann-it/MeowChan/blob/v1.0.0/docs/plugins/using-plugins.md#experimental-sources-and-media-checks).

## Upgrading and returning to 0.9.0

Close every older writer before upgrading. Back up the whole profile and media,
and keep exports separately. Do not let 0.9.0 and 1.0 write to the same data
simultaneously. Trying a separate profile (`MEOWCHAN_PROFILE`) and media directory
first is useful.

1.0 writes **archive schema 5 and media manifest 4**. Older records remain
readable in 1.0, including bindings without the new optional evidence. There is
no supported downgrade of a profile changed by 1.0: to try 0.9.0 after a problem,
use an untouched profile or restore your pre-upgrade backup to a separate
location. Keep the 1.0 data available when reporting the issue.

## Library and SDK compatibility

The Library, PluginSdk and optional PluginHost package version is `1.0.0`; the
independent plugin SDK protocol contract remains `1.0.0`. Their public APIs are
**not stable throughout 1.x**. Plugin authors should use the exact delivered SDK
package and consult the
[author guide](https://github.com/grassmann-it/MeowChan/blob/v1.0.0/docs/plugins/README.md).
Local C# plugins run with user permissions; worker separation is not an OS sandbox.

Custom library providers must explicitly bind new captured attachment revisions
to the acquisition committed by the media store. Downloading without references
and later capturing matching metadata no longer creates an implicit association.
Update the provider logic and rebuild; recompilation alone does not migrate that
behavior. See the
[migration note](https://github.com/grassmann-it/MeowChan/blob/v1.0.0/CHANGELOG.md#breaking-librarysdk)
and [package consumer example](https://github.com/grassmann-it/MeowChan/blob/v1.0.0/samples/LibMeowChan.Consumer/README.md).

## Known limits

- Automated and hosted native checks apply to their recorded source and
  environment. Everyday testing is not comprehensive across every platform and
  device; physical audio/GPU/FUSE behavior and complete screen-reader/IME coverage
  remain limited.
- Source reachability and future provider behavior are not guaranteed. Live
  checks use bounded samples; they do not establish availability of every board,
  thread or attachment, or prove the causes of every historical metadata conflict.
- Plugin-supplied names and parameter labels can remain in English; the host
  interface follows its selected language.
- macOS packages are ad-hoc signed and not notarized.
- Automatic settings-backup recovery disables recovered experimental-source
  exceptions until you explicitly grant them again. Valid primary settings keep
  their saved choices.

## Report a problem

[Open an issue](https://github.com/grassmann-it/MeowChan/issues/new) with the exact
version/package, OS/CPU, display scaling, view mode, reproduction steps, expected
and actual behavior. Mention whether the profile is fresh or upgraded and which
plugins are enabled. Relevant logs and screenshots help. If you try 0.9.0 as a
fallback, use a separate untouched profile or pre-upgrade backup and include
whether the problem also occurs there.
