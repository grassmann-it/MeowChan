# MeowChan 1.0.0 — release text template

**UNRELEASED TEMPLATE — native acceptance and the stable freeze are open.**
This file announces no downloads. Replace this banner only after the stable
candidate has the completed evidence recorded in the
[preparation handoff](v1.0.0-preparation.md).

MeowChan 1.0 introduces the Semi + Ursa interface for downloads, local reading,
the gallery, archive search and settings. Sources and image filters are supplied
as plugins, with an overview for enablement, revisions and access decisions.
The packaged compiler and worker support explicitly selected local C# source
files without requiring an end-user .NET SDK.

The supplied sources are 4chan, 8kun, Lainchan and the experimental Kohlchan,
Wizchan and Endchan examples. Provider metadata can conflict with original media;
experimental source exceptions require an explicit per-source/profile choice.
Revoking that choice must remain effective after restart and automatic config
recovery. Source availability is not guaranteed.

Back up the whole profile and media before upgrading from 0.9.0, and retain exports
separately. Close older writers first. A profile modified by 1.0 has no promised
downgrade path; use the untouched backup to return to 0.9.0. Trying an isolated
test profile first remains useful.

The Library, PluginSdk and optional PluginHost package version will be `1.0.0`;
the independent SDK protocol contract remains `1.0.0`. Their public APIs are
reviewed for this release; future 1.x API stability follows the documented package
contract, rather than a promise inferred from this template. Local plugins run
with user permissions; worker separation is not an OS sandbox.

macOS delivery remains ad-hoc signed without Developer ID/notarization unless
the final candidate explicitly proves a different signing state. Follow the
[first-launch guidance](../macos-signing.md). Keep any final limitations here;
the open [native matrix](v1.0.0-native-checks.md) must not disappear by changing
the product version.

Before using this text: insert the exact stable source commit, inventory/hash
links, verified platforms and actual remaining limitations. Replace relative
documentation links with links pinned to that reviewed commit/tag for GitHub.
Only link downloads that exist in the reviewed stable inventory. The current
stable recommendation remains 0.9.0 until a separately authorized publication.
