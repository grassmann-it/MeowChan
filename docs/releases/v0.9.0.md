# MeowChan 0.9.0 — a new home for your offline threads

Download MeowChan 0.9.0 from the [stable release](https://github.com/tfgrass/MeowChan/releases/tag/v0.9.0). Extract the complete package for your platform before launching it.

MeowChan 0.9.0 gives the cross-platform imageboard downloader a redesigned Avalonia desktop interface: clearer navigation, a new cat identity, dark and light themes, and a connected path from downloading a thread to reading its saved posts and browsing its media offline. It still starts simply. **Barebones is the default for new profiles**; Simple and Advanced show more detail without changing the running downloads.

## What's new

- **Three views, your own layout.** Switch among Barebones, Simple and Advanced while downloads continue. Each view keeps its own table columns, their order and widths, archive layout, density and reading size. Choose columns directly in Downloads, Boards and Archive, or reset the current table. The header cat opens About.
- **An archive built for reading.** Search captured posts and saved media, follow local quotes and backlinks, and read threads in the large reader. Browse images and video in the shared gallery, with zoom, pan, optional saved-post context and fullscreen. When you leave the gallery, the reader follows the post belonging to the currently displayed media, including after browsing forward or back; list and search origins retain their place too. New posts can be loaded when you choose, or followed live on an active watch.
- **Faster work with several threads.** Select multiple watches or archived threads for copy, removal and HTML export. Export selected threads as one portable offline collection. Saved List and Table archive layouts, a resizable reader split, consistent context commands and keyboard help make the same actions available throughout the workspace.
- **More control over boards and media.** A board-intake wizard previews discovered threads, title/opening-post filters and reasons before adding a batch. Rules inherit from Global through Source, Board and Thread. Pause cancels active checks and transfers; durable missing-media retries, a separate manual repair action and Diagnostics make interrupted or incomplete work easier to understand.
- **Favorites, originals and safe cleanup.** Mark exact saved-media revisions as favorites and export verified originals without downloading again. Permanent archive deletion previews the local files it will remove and requires confirmation; ordinary Delete removes watches while keeping their archive. Repeat HTML export can update a recognized earlier result, preserving a backup when existing output has changed or would be reduced.
- **A desktop that keeps your place.** Downloads, Archive, Sources, Rules, Diagnostics and Settings share one workspace. Navigation retains input, selection and running downloads. Settings has separate Close to tray and Minimize to tray choices, plus Dark, Light or System theme, English or German, and optional JSON language packs.

MeowChan watches supported 4chan and 8kun threads and boards, saves selected original media and can capture posts for offline reading. The [user guide](../Help.md) covers controls, media rules, retry behavior, exports and first launch.

## Upgrading

Existing watched URLs, settings and assigned media paths remain usable. Back up both the profile and media directories before upgrading, and do not run an older application against the same profile or media destination at the same time. New profiles use `.MeowChan` and `Downloads/MeowChan`; an existing sole legacy profile is used in place. If both profile directories exist, choose one with `MEOWCHAN_PROFILE`. The [upgrade guide](../Help.md) explains these paths and the new data formats, which are not supported for downgrade.

The reusable library is now **`libmeowchan`**, with `MeowChan.*` namespaces. Library consumers must update package, assembly and namespace references; there is no automatic NuGet redirect or binary compatibility. The .NET 10 source baseline remains. Check the [release assets](https://github.com/tfgrass/MeowChan/releases/tag/v0.9.0) for library package availability.

The [platform validation record](../platform-support.md) documents package checks and their evidence boundaries. Screenshots and source-built tests alone do not establish behavior on every physical device.
