# Windows x64 preview check

Use the actual **1.0.0-alpha.2 Windows x64** archive when available. The earlier
0.9.0 platform feedback does not validate this candidate. This is a manual native
check; an unrun step remains **not tested**.

1. Record Windows version, CPU, display scaling and archive filename/SHA-256
   (`Get-FileHash -Algorithm SHA256 'C:\path\package.zip'`). Extract the whole
   archive to a new folder, preferably with a space in its path. Keep all helper,
   native-library and compiler/reference files together. Use a machine without a
   developer SDK for the SDK-free claim; record if an SDK is installed instead.
2. In a new PowerShell window, choose an unused test profile, then start from a
   different working folder. Substitute the real executable path:

   ```powershell
   Remove-Item Env:OCHAN_PROFILE -ErrorAction SilentlyContinue
   $env:MEOWCHAN_PROFILE = Join-Path $env:TEMP ('MeowChan-alpha2-' + [guid]::NewGuid())
   $env:MEOWCHAN_DISABLE_UPDATE_CHECK = '1'
   Set-Location $env:TEMP
   & 'C:\Test Packages\MeowChan-alpha2\MeowChan.exe'
   ```

3. Check About shows `1.0.0-alpha.2`. In Settings select a separate test media
   folder. Start in Barebones; add one deliberately chosen small thread, pause
   and resume, open its folder, read captured posts and open the gallery. Try
   Up/Down through short and tall posts, Left/Right across selected threads,
   zoom and Escape back to the reader. Record unexpected jumps or blank content.
4. Prepare a source-file candidate using the [first-session recipe](../plugins/using-plugins.md#first-session),
   then open **Source, editor and test**. Run **Build and test**, then **Fetch test URL**
   for a supported small URL. Record actual
   compiler/test diagnostics. The test must not add a watch. To check the
   dimensions filter, follow the [first-session recipe](../plugins/using-plugins.md#first-session)
   with one intended source scope and controlled JPEG/PNG inputs.
5. Enter an invalid numeric setting, move focus away, save and correct it. Try
   Tab/Shift+Tab, spinner buttons and common shortcuts at the recorded scaling.
   If using Narrator/NVDA, record its version and the actual spoken labels/focus.
   A visual keyboard check alone is not screen-reader acceptance.
6. Enable close/minimize-to-tray one at a time, hide and restore, then choose
   **Exit**. Confirm MeowChan and its owned plugin/compiler workers end in Task
   Manager. Restart with the same profile while offline; verify saved posts,
   gallery media and export remain usable. An unfinished live watch may report
   an offline error; it must not prevent opening saved content.

For an upgrade check, first create a **dedicated 0.9.0 test profile** with its own
test media directory and small saved thread/export. Exit 0.9.0, back up those test
directories, then launch alpha.2 with that same explicit `MEOWCHAN_PROFILE`.
Check settings, watches, originals, favorites and exports before and after another
restart. Do not use a copied personal profile whose settings still point at the
original media directory. Return to 0.9.0 using the untouched test backup.

Report each step as **pass**, **problem** with reproduction, or **not tested**.
Include version/package hash, fresh versus upgraded profile, plugin names, logs
or screenshots and the exact failing keys/actions. Do not mark SDK-free, upgrade,
offline or screen-reader checks passed unless those conditions were actually used.
