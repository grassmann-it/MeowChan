## Small executable package checks

Use a disposable account/desktop for Windows/macOS. Linux runners below create
their own desktop; never add `--native-display` or attach a personal DISPLAY.
Set absolute paths to the actual package, extracted root, executable, fresh
evidence directory and full source commit. Keep extraction and original archive
together. Do not rename an older package to satisfy identity checks.

Linux, on a CPU matching `linux-x64` or `linux-arm64`:

```sh
# Set MC_ARCHIVE, MC_ROOT, MC_APPHOST, MC_SOURCE, MC_EVIDENCE and MC_RID first.
sha256sum "$MC_ARCHIVE" "$MC_APPHOST"
flock /tmp/meowchan-ui-1.0-build.lock python3 scripts/check-desktop-package.py "$MC_ROOT" "$MC_RID"
flock /tmp/meowchan-ui-1.0-build.lock python3 scripts/package-plugins.py --verify "$MC_ROOT" --runtime "$MC_RID"
flock /tmp/meowchan-ui-1.0-build.lock python3 scripts/apphost-workflow-smoke.py "$MC_APPHOST" --archive "$MC_ARCHIVE" --archive-root "$MC_ROOT" --archive-member MeowChan --source-commit "$MC_SOURCE" --runtime "$MC_RID" --scale 1 --scale 1.5 --scale 2 --evidence-dir "$MC_EVIDENCE/workflow"
flock /tmp/meowchan-ui-1.0-build.lock python3 scripts/apphost-plugin-workflow-smoke.py "$MC_APPHOST" --archive "$MC_ARCHIVE" --archive-root "$MC_ROOT" --archive-member MeowChan --source-commit "$MC_SOURCE" --evidence-dir "$MC_EVIDENCE/plugin-workflow"
flock /tmp/meowchan-ui-1.0-build.lock python3 scripts/apphost-source-activation-smoke.py "$MC_APPHOST" --archive "$MC_ARCHIVE" --archive-root "$MC_ROOT" --archive-member MeowChan --source-commit "$MC_SOURCE" --evidence-dir "$MC_EVIDENCE/source-activation" --timeout 120 --scale 1
flock /tmp/meowchan-ui-1.0-build.lock python3 scripts/apphost-playback-smoke.py "$MC_APPHOST" --evidence-dir "$MC_EVIDENCE/playback"
```

The `MeowChan` member above is for the TAR root. For AppImage use the member
`usr/lib/meowchan/MeowChan` and the exact AppImage/extracted AppDir; the maintained
distribution gate runs both extracted and extract-and-run paths. With already
available, pinned native-architecture images, its command is:

```sh
# MC_PACKAGES contains the three artifacts and their package manifest.
# MC_NO_VLC_IMAGE and MC_SYSTEM_VLC_IMAGE are inspected existing image IDs/tags.
flock /tmp/meowchan-ui-1.0-build.lock python3 scripts/linux-distribution-gates.py --package-dir "$MC_PACKAGES" --manifest "$MC_PACKAGES/$MC_RID-package-manifest.json" --no-vlc-image "$MC_NO_VLC_IMAGE" --system-vlc-image "$MC_SYSTEM_VLC_IMAGE" --source-commit "$MC_SOURCE" --runtime "$MC_RID" --evidence-dir "$MC_EVIDENCE/distributions"
```
