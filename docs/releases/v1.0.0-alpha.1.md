# MeowChan 1.0.0-alpha.1 — early preview 🐾

**This is an optional preview of MeowChan 1.0.0. For everyday use, [0.9.0 remains the stable recommendation](https://github.com/tfgrass/MeowChan/releases/tag/v0.9.0).** You can stay on 0.9.0 and wait for a later release.

1.0.0 brings improvements we would love your feedback on, but this alpha has not been comprehensively tested in everyday use or across all supported platforms. Automated tests and local GUI checks cover parts of the application; they do not make this a stable release. Expect bugs and rough edges.

## What to try

- **The Semi + Ursa interface.** The existing MeowChan layout and workflows remain familiar. Barebones is still a complete everyday view; Simple, Advanced and explicitly opened details offer more control.
- **Source and image-filter plugins.** Manage plugins and their settings and permissions, try the Lainchan/Kohlchan examples, or add C# source plugins using the bundled compiler. New builds and plugin/source settings take effect on the next start. See the [plugin guide](https://github.com/tfgrass/MeowChan/blob/b8e8c5cf2439c276ec0b64d09bd82d35146f808f/docs/plugins/using-plugins.md).
- **Download, archive and reader improvements.** Local download search, clearer selection and export actions, keyboard navigation, settings validation and optional reading-position resume are among the changes being tried in 1.0.

## Before you try it

Use a separate test profile (`MEOWCHAN_PROFILE`) and a separate media download directory. Back up your existing profile and media before trying an upgrade. Do not run both versions against the same profile or media directory at the same time, and do not rely on 0.9.0 being able to reopen a profile changed by the alpha. To return to 0.9.0, use your untouched profile or backup.

## Known limitations

- Reader keyboard navigation can select a post outside the visible area, especially with mixed-height content and page boundaries. Scrolling and return positions are still being revised.
- Native accessibility validation is incomplete. Numeric spinner buttons have a known first-focus problem in the Linux screen-reader checks.
- Full native package validation and independent everyday testing across Windows, macOS and Linux are still outstanding. A passing build alone does not establish that every platform works correctly.

## Please report bugs

[Open a GitHub issue](https://github.com/tfgrass/MeowChan/issues/new) if something breaks or feels wrong. Include **MeowChan version, OS and architecture, display scaling, view mode, steps to reproduce, expected result and actual result**. Relevant logs or screenshots help too. Please mention whether you used a fresh profile or upgraded from 0.9.0, and which plugins were enabled.

Thank you for helping test the preview. Staying on 0.9.0 is completely fine. 🐾
