# Source-text test inventory

Reviewed on 1.2.0 at `4f29e9cbf` for `test-hygiene-120`. The inventory covers tests
that inspect checked-in product or smoke source and markup. It includes tests that
reach `File.ReadAllText`, line readers, or XML/Roslyn parsers through helpers,
and equivalent Python checks. Generated files, fixture data, language-pack JSON,
Markdown-only checks, and evidence hashes are outside this scope. The intentional
`CodeHygieneTests` and `Hygiene/FireAndForgetHygieneTests` scans are excluded
from the review.

| Evaluation | Meaning |
| --- | --- |
| Keep | The source is the input to an intentional lint, static coverage, or packaging rule. |
| Replace | Source assertions infer runtime behavior from the implementation. Exercise the compiled code, rendered UI, or callable smoke entry point when replacing them. |
| Delete | Existing executable coverage already performs the check. |
