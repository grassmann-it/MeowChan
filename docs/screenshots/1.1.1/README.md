# MeowChan 1.1.1 screenshots

Unedited PNGs of the English dark interface, captured on 2026-11-23 from a Linux x64 Release build of the application source at `270714178`. The desktop smoke harness ran at 1× scale in a private Xvfb display with Openbox, a private D-Bus session and software rendering. The captures show the application client area.

The Reader and Media page use the offline landscape fixture. Downloads and Tagging show synthetic rows, and the Booru workbench uses in-memory results and generated previews. The captures contain fixture data only. See the release notes for the status of Windows and macOS package acceptance. [Validation status](../../releases/v1.1.1.md#validation-status)
