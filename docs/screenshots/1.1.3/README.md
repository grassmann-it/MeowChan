# MeowChan 1.1.3 screenshots

These 1440 × 900 PNGs were captured from the Linux release build at `927ade030` on a private Xvfb display with an XRender compositor at 1× scale. The app used a separate profile and download folder. The archive favourites capture shows the central 1440 pixels of a 1452-pixel window so the archive table and Reader appear together.

The cat photos, GIF and posts come from public SFW 4chan threads, including Cat General (`/kot/`) on `/an/`. The Booru views show saved Danbooru search results filtered to General. Third-party material illustrates the interface and belongs to its respective creators. The gallery checkerboard uses the project’s own [MeowChan artwork](../../../Assets/branding/meowchan-source.png).
