# MeowChan 1.1.2 screenshots

These 1440 × 900 PNGs show the Advanced workspace in the Linux release build at `66a5c5925`. The showcase ran at 1× scale on a private Xvfb display with an XRender compositor. Each file is a full-size copy of the original capture.

The photos, clips and posts come from public SFW threads on 4chan, including the `/kot/` (Cat General) threads on `/an/`, the `/rpt/` threads on `/p/`, and threads on `/wsg/`. The board archive shows a recorded excerpt from `/an/`. The Booru views show public Danbooru results filtered with `rating:general`. Third-party material appears here solely to illustrate the interface. Copyright remains with the respective creators.
