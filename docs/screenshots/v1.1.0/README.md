# MeowChan 1.1.0 screenshots

Application captures of the 1.1.0 interface, taken on 2026-11-19 from a local
Release build of the 1.1.0 media/test-fix tree with the desktop smoke harness
(`scripts/run-desktop-smoke.py`, `visual` and UI catalog scenarios). They are
unedited PNGs from the real application UI using synthetic offline
demonstration data (`ShowcaseData`): no live watches, HTTP requests or personal
profiles. Capture conditions: Linux, private Xvfb, Openbox, private DBus and
software rendering; captures exclude native window decorations.

Gallery and media focus are 1440×920 (same scene as the 1.0.x captures); all
other images are 1380×850 catalog captures. Images are English and dark unless
the name says `light` or `german`. The archive table capture is light.
